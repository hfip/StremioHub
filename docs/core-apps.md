# Apps & Forks

Stremio ships as a free, open-source media center. The official app covers the basics; the
community builds forks and alternative clients when you want a newer UI, better codec support or
features the official app does not have yet.

## Official apps

- ⭐ **[Stremio](https://www.stremio.com/)** / [Downloads](https://www.stremio.com/downloads) —
  Free, open-source media center. Windows, macOS, Linux, Android, Android TV, LG webOS and
  Samsung Tizen. The current release is Stremio 5 (beta channel).
- **[Stremio Web](https://web.stremio.com/)** — The browser client. It is the recommended way to
  use Stremio on iPhone and iPad, where there is no native app.
- **[Stremio Shell](https://github.com/Stremio/stremio-shell)** — The official Qt-based desktop
  shell. Build it yourself if you want to run the desktop app from source.
- **[stremio-shell-ng](https://github.com/Stremio/stremio-shell-ng)** — The official next-generation
  shell (WebView2 + mpv, written in Rust). The base that most modern desktop forks build on.
- **[Stremio Service](https://github.com/Stremio/stremio-service)** — The local streaming server
  the desktop app talks to. Useful if you run Stremio on a headless box or a home server.

## Desktop clients & forks

- ⭐ **[Stremio Enhanced](https://github.com/REVENGE977/stremio-enhanced)** — Electron-based
  desktop client with support for **plugins and themes**. Actively developed and the safest
  "power user" choice on Windows, macOS and Linux.
- ⭐ **[Stremio Community v5](https://github.com/Zaarrg/stremio-community-v5)** — WebView2 and
  Qt6 shell that pairs the latest Stremio web UI with a native player. The base most other
  desktop forks are built on.
- **[Stremio Kai](https://github.com/allecsc/Stremio-Kai)** — A refined fork of Stremio Community
  v5 with a modern UI, HDR passthrough, intro skipping, and tuning for anime and lower-end PCs.
- **[Nuvio](https://nuvio.tv/)** — A separate modern client that reads the same Stremio add-on
  manifests. Worth a look if you want something that is not Stremio itself.

## Mobile & TV

- **[Stremio for Android / Android TV](https://play.google.com/store/apps/details?id=com.stremio.one)**
  — The official mobile and TV apps.
- **[Alder](https://github.com/aradhyas8/Alder)** — Android TV client built on Stremio, with a
  TV-first interface.
- **[Lumera](https://github.com/LumeraD3v/Lumera)** — Android TV app that plays your existing
  Stremio add-ons.
- **[Raffi](https://github.com/kaleidal/raffi)** — Modern streaming client built around Stremio
  add-ons, with a fast player and one unified library.
- **[dxbi](https://github.com/notdxbi/dxbi-stremio)** — Netflix-style client for Windows, macOS,
  Linux, Android TV and Google TV.
- **[Hikari](https://github.com/codegeasse1/hikari)** — Universal streaming app for Stremio
  add-ons, scrapers and CloudStream extensions.
- **[ynotv](https://github.com/tbeezy/ynotv)** — Free Windows IPTV player with Stremio and Nuvio
  integration.

## Web clients

- **[Stremio Web](https://web.stremio.com/)** — The official web client. Install it as a PWA and
  it behaves almost like a native app.

## Before you install a fork

- Forks are **unofficial**: the Stremio team does not support them, and bugs belong in the fork's
  GitHub issues.
- Download only from the **Releases** page of the fork's GitHub repository, never from a file
  locker or a Telegram channel.
- A fork can lag behind on security and add-on compatibility. If something stops working after a
  Stremio update, the fork is the usual suspect.
- On iPhone and iPad, use Stremio Web: there is no official native iOS app, and sideloaded builds
  are not worth the hassle.
