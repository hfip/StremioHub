# Credits & sources

None of this exists in a vacuum. This page lists the projects and people whose work made the guides
possible, and explains how the content here was produced.

## Guides

- **[Viren070's Guides](https://guides.viren070.me/)** — the inspiration for this section's structure
  and the best English reference for AIOStreams, Comet and Stremio in general. Go read it; it goes
  deeper than we do.
- **[ElfHosted docs](https://docs.elfhosted.com/)** — clear, honest writing about add-ons, providers
  and rate limits.
- **[r/StremioAddons](https://www.reddit.com/r/StremioAddons/)** — where most of the practical
  knowledge in this ecosystem is debugged in public.

::: info How these guides were written
The text on this site is written independently, in our own words, in English and Arabic. We link to
the original projects instead of copying their documentation. If a guide and the upstream docs
disagree, the upstream docs win — and please open an issue so we can fix ours.
:::
