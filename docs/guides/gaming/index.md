# Gaming

This section covers running older PC games on community infrastructure when the official servers are
gone. It is a small section on purpose: most of this site is about streaming, and the same legal
questions apply.

## What is here

- **[Plutonium](/guides/gaming/plutonium)** — a free client and server browser for older Call of Duty
  titles (World at War, Black Ops, Black Ops II, Modern Warfare 3).

## Before you start

- These projects keep abandoned multiplayer games alive. They do not give you a licence to the game
  files.
- Downloading copyrighted game files may be illegal where you live, **even if you own a disc**.
- Community clients can be flagged by anti-cheat systems in other games. Keep them separate from
  anything you play competitively.

## General advice

- Use a dedicated folder per game (`C:\Games\...`), never `Program Files`.
- Exclude that folder from real-time antivirus scanning if you trust the source; installers are
  frequently false-positived.
- Verify checksums or signatures when the project publishes them.
- Back up your config and keybinds; community launchers occasionally reset profiles.
