# معاينة الخطوط

هذه صفحة مؤقتة لمقارنة الخطوط العربية قبل اعتمادها. نفس النص والعناصر معروضة بأربعة خطوط،
وبعد الاختيار ستُحذف الصفحة ويُطبّق الخط المختار على كل الموقع.

  <div class="font-demo__title">دليل ستريمو الشامل</div>
  <h2>التطبيقات والنسخ المعدّلة</h2>
  <p>
    ستريمو تطبيق مركز وسائط مجاني ومفتوح المصدر. التطبيق الرسمي يغطي الأساسيات، والمجتمع يبني نسخًا
    معدّلة عندما تريد واجهة أحدث أو دعمًا أفضل للترميز. ثبّت إضافة واحدة فقط — AIOStreams أو Comet —
    ثم أضف AIOMetadata ليظهر الكتالوج بالشكل الصحيح.
  </p>
  <ul>
    <li><strong>AIOStreams</strong> — إضافة «ميتا» تسأل عدة إضافات بث بالتوازي وتدمج النتائج.</li>
    <li><strong>Torrentio</strong> — الكلاسيكي، يدعم معظم خدمات Debrid.</li>
  </ul>
</div>
