# الأدوات والمساعدات

أشياء تجعل التعامل مع ستريمو أسهل: إدارة الإضافات، نقل إعداداتك بين الحسابات، بناء الكتالوجات،
تحميل الحلقات للمشاهدة بدون إنترنت، والاستضافة الذاتية.

## إدارة الإضافات

- ⭐ **[Stremio Addon Manager](https://github.com/pancake3000/stremio-addon-manager)** /
  [تطبيق الويب](https://stremio-addon-manager.pages.dev/) — أعد ترتيب الإضافات وأضفها واحذفها
  بدون إعادة تثبيت كل شيء. اربط حساب ستريمو واسحب القائمة بالترتيب الذي تريده.
- ⭐ **[Stremio Account Bootstrapper](https://github.com/JourneyDeprecated/stremio-account-bootstrapper)** —
  يطبّق إعدادًا محفوظًا (الإضافات، الترتيب، الإعدادات) على حساب ستريمو بضغطات قليلة. مفيد
  للأجهزة الجديدة وأفراد العائلة. توجد نسخة معدّلة تدعم
  [Nuvio](https://nuvio.tv/) أيضًا [هنا](https://github.com/burggraf/stremio-account-bootstrapper).
- **[PimpMyStremio](https://github.com/sungshon/PimpMyStremio)** — مدير إضافات محلي يستطيع تشغيل
  إضافات يرفض التطبيق العادي تحميلها. مشروع قديم، استخدمه بحذر.
- **[AIOManager](https://aiomanager.elfhosted.com)** — تطبيق ويب يحفظ إضافات عدة حسابات متزامنة
  وينسخ إعداداتك احتياطيًا.

## الكتالوجات وتطوير الإضافات

- **[Stremio Catalog Builder](https://stremio.github.io/stremio-catalog-builder/)** — الأداة
  الرسمية لبناء كتالوجات مخصّصة بدون كتابة كود.
- **[مساعد نشر الإضافات](https://stremio.github.io/stremio-publish-addon/index.html)** — مساعد
  رسمي لنشر إضافتك في مجموعة المجتمع.
- **[Stremio Add-on SDK](https://github.com/Stremio/stremio-addon-sdk)** — SDK لـ Node.js، أسرع
  طريقة لكتابة إضافتك.
- **[دليل الإضافات](https://stremio.github.io/stremio-addon-guide/)** — الدليل الرسمي لبروتوكول
  الإضافات من الصفر.

## التحميل والمشاهدة بدون إنترنت

- **[Stremio Downloader](https://github.com/BurningSands70/stremio-downloader)** — ينزّل البث من
  ستريمو إلى قرصك.
- **[stremio-downloader](https://github.com/BurningSands70/stremio-downloader)** — نفس المشروع،
  يعمل بدون تطبيق الكمبيوتر.

## الاستضافة الذاتية والمنصات

- **[stremio-docker](https://github.com/tsaridas/stremio-docker)** — صور Docker لخادم ستريمو
  ونسخة الويب. أسهل طريقة لتشغيل ستريمو على NAS أو سيرفر منزلي.
- **[Stremio Service](https://github.com/Stremio/stremio-service)** — خدمة البث المحلية الرسمية،
  إذا أردت تشغيلها منفصلة عن الواجهة.
- **[Stremio Server Docker](https://github.com/Stremio/server-docker)** — صور الخادم الرسمية.
- **[Stremio على Raspberry Pi](https://github.com/shivasiddharth/Stremio-RaspberryPi)** — سكربت
  تثبيت لراسبيري باي.
- **[Stremio Flatpak](https://github.com/bilelmoussaoui/stremio-flatpak)** — حزمة Flatpak لسطح
  مكتب لينكس.

## اختيارات سريعة

| إذا أردت… | ثبّت |
| --- | --- |
| إعادة ترتيب إضافاتك | Stremio Addon Manager |
| نقل إعدادك لجهاز جديد | Stremio Account Bootstrapper |
| بناء كتالوج مخصّص | Stremio Catalog Builder |
| حفظ حلقات لرحلة | Stremio Downloader |
| تشغيل ستريمو على سيرفر/NAS | stremio-docker |

::: warning
أدوات الطرف الثالث تطلب الوصول إلى حساب ستريمو. استخدم تطبيق الويب الرسمي أو أداة مفتوحة المصدر،
وألغِ الوصول بعد الانتهاء. لا تضع كلمة مرورك في موقع عشوائي — تسجيل دخول ستريمو يعتمد على رمز
(token) وليس كلمة المرور.
:::
