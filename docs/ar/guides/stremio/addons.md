# كيف تعمل الإضافات

كل مشكلة في ستريمو تعود في النهاية إلى هذه الصفحة. عشر دقائق هنا توفّر ساعات لاحقًا.

## الإضافة خدمة ويب

ستريمو لا ينزّل كودًا. عندما «تثبّت» إضافة فأنت تحفظ **رابط manifest** — رابط لملف JSON يصف خدمة
تعمل في مكان آخر.

```json
{
  "id": "com.example.addon",
  "version": "1.0.0",
  "name": "Example",
  "resources": ["catalog", "meta", "stream"],
  "types": ["movie", "series"],
  "idPrefixes": ["tt"]
}
```

عند فتح عمل، يستدعي ستريمو تلك الخدمة عبر HTTPS ويعرض الجواب. لهذا:

- يمكن أن تتعطل إضافة دون أن يتحدّث ستريمو.
- بيانات Debrid الخاصة بك تكون على سيرفر الإضافة إن استخدمت نسخة عامة.
- «تثبيت» تعني فعليًا «تذكّر هذا الرابط».

## أنواع الموارد الأربعة

| المورد | وظيفته | مثال |
| --- | --- | --- |
| `catalog` | قوائم قابلة للتصفح في Board وDiscover | الرائج، نتفليكس، IMDb Top 250 |
| `meta` | العناوين والبوسترات والأوصاف والحلقات | Cinemeta، AIOMetadata، TMDB |
| `stream` | مصادر قابلة للتشغيل | AIOStreams، Comet، Torrentio |
| `subtitles` | مسارات الترجمة | OpenSubtitles، SubDL |

الإضافة الواحدة قد توفّر أكثر من مورد. AIOStreams تقدّم `stream` فقط، وAIOMetadata تقدّم
`meta` و`catalog`.

## نسخة عامة أم استضافة ذاتية

معظم الإضافات خدمات مفتوحة المصدر يشغّلها شخص للعامة.

- **نسخة عامة** — بدون إعداد، لكن الحدود مشتركة، وتوكن Debrid محفوظ على سيرفر شخص آخر.
- **استضافة ذاتية** — حاويتك، حدودك، وبياناتك تبقى معك. تحتاج [Docker](/ar/guides/self-hosting/docker)
  وسيرفرًا صغيرًا.

إن استخدمت نسخة عامة مع حساب Debrid، فضّل نسخة يشغّلها مشغّل معروف، وتذكّر أنك تستطيع إلغاء توكن
الـ API من موقع المزوّد في أي وقت.

## لماذا الإضافات الأكثر أبطأ

ستريمو يسأل كل إضافات البث عن كل عمل، بالتوازي. ثم كل إضافة تستعلم مصادرها. مع ست إضافات بث تحصل
على:

- انتظار أطول قبل ظهور القائمة،
- نتائج مكررة،
- احتمال أكبر أن تتأخر إضافة أو تنتهي مهلتها وتؤخّر الباقي.

إضافتا بث تكفيان. مجمّع واحد (AIOStreams) مع بديل بسيط (Comet) يغطي كل شيء تقريبًا.

## التركيبة المعقولة

1. **البث:** [AIOStreams](/ar/guides/stremio/aiostreams)
2. **البديل:** [Comet](/ar/guides/stremio/comet) — اختياري
3. **الميتاداتا:** [AIOMetadata](/ar/guides/stremio/metadata) أو Cinemeta المدمجة
4. **الترجمة:** OpenSubtitles (مدمجة)
5. **إضافات:** Trakt للسجل، RPDB لتقييمات البوسترات

## الترتيب مهم

تُسأل الإضافات بترتيب ظهورها في قائمتك. [Addon Manager](/ar/guides/stremio/extras) يتيح سحبها
دون إعادة تثبيت. ضع الأسرع والأكثر موثوقية أولاً.

## قراءة رابط الـ manifest

- ينتهي بـ `manifest.json`.
- يستخدم HTTPS. ستريمو يرفض HTTP العادي في معظم العملاء.
- الإضافة المضبوطة لها مسار طويل غير مقروء — هذا المسار يرمّز إعداداتك (وأحيانًا توكن Debrid).
  تعامل معه ككلمة مرور.
- إذا غيّرت الإعدادات في صفحة الضبط فستحصل على رابط **جديد** ويجب إعادة التثبيت. القديم يبقى
  يعمل بالإعدادات القديمة.
