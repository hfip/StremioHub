# خدمات Debrid

خدمة Debrid تنزّل التورنت على سيرفراتها وتعطيك رابط HTTPS مباشرًا. هذه الفكرة كلها، وهي تغيّر تجربة
ستريمو أكثر من أي اختيار آخر للإضافات.

## لماذا يستخدمها الناس

| بدون Debrid | مع Debrid |
| --- | --- |
| عنوان IP الخاص بك ينضم لشبكة التورنت | لا يلمس IP الشبكة إطلاقًا |
| التشغيل يعتمد على الـ seeders | التشغيل من مركز بيانات |
| الأعمال الشهيرة سريعة والقديمة تتعطل | الأعمال القديمة غالبًا مخزّنة مسبقًا |
| مزوّد الإنترنت يرى حركة BitTorrent | يرى اتصال HTTPS واحدًا |

## المزوّدون

| المزوّد | ملاحظات |
| --- | --- |
| [Real-Debrid](https://real-debrid.com/) | الأكثر تكاملًا وأكبر كاش. مشاكل أحيانًا مع الاستضافة وإشعارات DMCA. |
| [AllDebrid](https://alldebrid.com/) | منافس قريب؛ كاش تورنت موثوق ودعم إضافات جيد. |
| [Premiumize](https://www.premiumize.me/) | Debrid + تخزين سحابي + Usenet في اشتراك واحد. أغلى. |
| [TorBox](https://torbox.app/) | Debrid وUsenet وكاش متنامٍ؛ بديل شائع بعد مشاكل RD. |
| [Debrid-Link](https://debrid-link.com/) | مزوّد أوروبي يدعم التورنت والاستضافة. |
| [Put.io](https://put.io/) | صندوق تورنت سحابي مصقول؛ كاش أصغر. |

الأسعار وحدود الاستخدام العادل تتغيّر باستمرار. راجع صفحة كل مزوّد، وابدأ بشهر واحد قبل الالتزام
بسنة.

## الحصول على مفتاح الـ API

كل مزوّد يخفي التوكن في قائمة مختلفة، والنمط واحد:

1. سجّل الدخول في موقع المزوّد.
2. ابحث عن **API** أو **API token** في إعدادات الحساب.
3. انسخ السلسلة الطويلة — لا كلمة المرور ولا اسم المستخدم.
4. الصقها في صفحة ضبط الإضافة.

تعامل مع التوكن ككلمة مرور: من يملكه يستطيع استهلاك حصتك. إن لصقته في نسخة عامة لا تتحكم بها،
فألغِه لاحقًا من موقع المزوّد.

## كيف يعمل الكاش

1. الإضافة تجد تورنتًا مطابقًا للفيلم.
2. تسأل المزوّد: *هل هذا info hash موجود في الكاش؟*
3. **مخزّن** → رابط فوري.
4. **غير مخزّن** → المزوّد ينزّله (دقائق إلى ساعات) ثم يصبح مخزّنًا للجميع بعده.

لهذا تشيع فلاتر «المخزّن فقط»: تخفي كل ما سيجب أن تنتظره.

## اضبطها في إضافتك

- **AIOStreams** → Services → Debrid → اختر المزوّد → الصق التوكن.
- **Comet** → Debrid Service + API key.
- **MediaFusion** → Streaming Provider → بيانات Debrid.
- **Torrentio** → قائمة المزوّد + المفتاح في صفحة الضبط.

مزوّد واحد يكفي. إضافة نفس المزوّد لخمس إضافات لا تزيد حصتك، بل تضاعف الطلبات فقط.

## حدود ستواجهها فعلاً

- **روابط الاستضافة** — Debrid يفتح أيضًا تحميل الملفات من مواقع الاستضافة، وهذه الروابط تنتهي
  صلاحيتها. لا تهم لستريمو وتزعج إن استخدمت المزوّد لأشياء أخرى.
- **إزالة DMCA** — تورنت مخزّن قد يختفي بين ليلة وضحاها. الإضافة ستتوقف عن عرضه ببساطة.
- **الاستخدام العادل** — «غير محدود» له دائمًا حد إساءة. مشاهدة موسم يوميًا أمر طبيعي؛ تشغيل
  seedbox ليس كذلك.
- **البث المتزامن** — معظم الخطط تسمح بعدد محدود من عناوين IP. عائلة تشترك بحساب في بيتين سترى
  أخطاء.

## هل تحتاج VPN أيضًا؟

- Debrid أو Usenet فقط → لا.
- إضافات P2P خام بدون Debrid → نعم، عنوان IP في الشبكة.
