# AIOStreams

AIOStreams إضافة **ميتا**: لا تبحث في مواقع التورنت بنفسها، بل تسأل إضافات بث أخرى (Torrentio
وComet وMediaFusion وProwlarr وJackett…) وتدمج أجوبتها في قائمة واحدة نظيفة ومرتبة.

- المستودع: [Viren070/AIOStreams](https://github.com/Viren070/AIOStreams)
- النسخة العامة: [aiostreams.elfhosted.com](https://aiostreams.elfhosted.com)
- التوثيق: [ويكي AIOStreams](https://github.com/Viren070/AIOStreams/wiki)

## لماذا نبدأ بها

- تثبيت واحد بدل خمسة.
- تحذف المكرر وترتّب النتائج حسب قواعدك.
- تضيف دعم Debrid وUsenet لإضافات لا تدعمهما (عبر StremThru).
- الفلاتر مركزية: الدقة والجودة والترميز والحجم واللغة وفريق الإصدار.

المقابل: خدمة إضافية بينك وبين المصدر، فإن تعطّلت النسخة أصبحت القائمة فارغة. لهذا ننصح بالاحتفاظ
بإضافة بث ثانية بسيطة كبديل.

## الخيار أ — النسخة العامة

1. افتح رابط النسخة وأنشئ إعدادًا.
2. أضف حساب **Debrid** في قسم *Services* (Real-Debrid، AllDebrid، Premiumize، TorBox،
   Debrid-Link…). الصق توكن الـ API لا كلمة المرور.
3. أضف **الإضافات** التي تريد أن تسألها:
   - أي إضافة تملك حق استخدامها — الصق رابط manifest الخاص بها
   - Comet — رابط manifest الخاص بك
   - MediaFusion — رابط manifest الخاص بك
   - Prowlarr / Jackett — إن كنت تستضيف فهارسك
4. اضبط **الفلاتر**: أقل دقة، استبعاد الجودات (CAM وTS)، أقصى حجم، اللغات المطلوبة.
5. اضبط **الترتيب**: نتائج Debrid المخزّنة أولاً، ثم الدقة، ثم عدد الـ seeders.
6. اختياريًا فعّل **البروكسي** إن كان مزوّد الإنترنت يخنق حركة Debrid.
7. اضغط **Install** وأكّد في ستريمو.

::: warning حدود النسخة العامة
نسخة ElfHosted العامة مشتركة ومحدودة الطلبات. إن أضفت خمس إضافات وحدّثت القائمة باستمرار ستصل
للحد. إما أن تصبر أو تستضيفها بنفسك.
:::

## الخيار ب — الاستضافة الذاتية

```bash
docker run -d --name aiostreams \
  -p 3000:3000 \
  -e SECRET_KEY=change-me \
  -v ./aiostreams-data:/app/data \
  ghcr.io/viren070/aiostreams:latest
```

ثم افتح `http://your-server:3000` واضبطها كما في النسخة العامة. ضعها خلف HTTPS — عملاء ستريمو
يرفضون manifest على HTTP عادي خارج localhost. Caddy أو Cloudflare Tunnel يكفيان؛ راجع
[أساسيات Docker](/ar/guides/self-hosting/docker).

## ماذا تضع فيها

| الإضافة | استخدامها |
| --- | --- |
| Torrentio | تغطية واسعة لتورنتات عامة |
| Comet | بديل سريع وخفيف |
| MediaFusion | محتوى إقليمي وغير إنجليزي |
| Prowlarr / Jackett | متتبّعاتك الخاصة |
| StremThru | Debrid/Usenet لإضافات لا تدعمهما |

ابدأ بـ **اثنتين**. أضف ثالثة فقط إذا استطعت تحديد النقص الذي تغطيه.

## الإعدادات المهمة فعلاً

- **المخزّن فقط (Cached only)** — يخفي التورنتات غير المخزّنة. تخسر الأعمال النادرة لكنك لا تنتظر
  تنزيلًا.
- **أقصى حجم** — 8–15 GB لـ 1080p، و25–60 GB لـ 4K. يمنع ملفات 90 GB من الظهور على جهاز TV.
- **الجودات المستبعدة** — CAM وTS وHDTS. لا أحد يريدها، وهي دائمًا أول القائمة.
- **حد النتائج** — 20–30 كافٍ؛ قائمة من 300 عنصر غير قابلة للاستخدام بريموت.
- **البروكسي** — فقط إذا كانت روابط Debrid المباشرة تعلّق. يضيف خطوة ونقطة فشل.

## مشاكل شائعة

**«لا توجد مصادر» في ستريمو لكن النتائج تظهر في صفحة AIOStreams** — الـ manifest المثبّت قديم.
أعد تثبيت الرابط الأحدث بعد حفظ الإعدادات.

**كل النتائج غير مخزّنة** — توكن Debrid خاطئ أو منتهٍ أو الحساب بلا اشتراك نشط.

**نتائج Torrentio فقط هي التي تظهر** — الإضافات الأخرى ترجع أخطاء. افتح لوحة AIOStreams وتحقق من
حالة كل إضافة.

**القائمة بطيئة** — إضافات أكثر من اللازم أو إحداها تنتهي مهلتها. احذف البطيئة.
