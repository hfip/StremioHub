# نظرة عامة على ستريمو

ستريمو مركز وسائط مجاني ومفتوح المصدر، لكنه ليس خدمة بث: هو واجهة تعرض ما تُرجعه **الإضافات**.
هذه الفكرة وحدها تفسّر كل سلوكه تقريبًا — بما فيه أنه يبدو فارغًا بعد التثبيت.

## الأجزاء

| الجزء | وظيفته |
| --- | --- |
| **العميل** | التطبيق الذي تفتحه: كمبيوتر، أندرويد، تلفاز، أو نسخة الويب |
| **الحساب** | يحفظ مكتبتك وقائمة إضافاتك وتقدّم المشاهدة |
| **الإضافات** | خدمات ويب توفّر كتالوجات أو ميتاداتا أو بثًا أو ترجمة |
| **خادم البث** | خدمة محلية تنزّل التورنت وتشغّله (في نسخة الكمبيوتر) |
| **خدمة Debrid** | خدمة مدفوعة اختيارية تحوّل التورنت إلى رابط HTTPS مباشر |

## كيف يعمل التشغيل

1. تفتح عملًا. يسأل ستريمو **إضافة ميتاداتا** (Cinemeta عادة) عن الوصف والبوستر وقائمة الحلقات.
2. تضغط تشغيل. يسأل ستريمو كل **إضافات البث** المثبّتة عن المصادر.
3. كل إضافة تُرجع قائمة روابط: تورنت، رابط HTTP مباشر، أو رابط Debrid.
4. يفتح المشغّل الرابط. في الكمبيوتر، ينزّل خادم البث أجزاء التورنت ويشاركها أثناء المشاهدة.

## ما تحتاجه

- جهاز من [قائمة التطبيقات](/ar/core-apps) — نسخة الكمبيوتر هي الأكثر قدرة.
- **إضافة بث واحدة**. اثنتان كحد أقصى إن كنت تعرف لماذا تحتاج الثانية.
- اختياريًا **اشتراك Debrid**، وهو يلغي جزء الند للند ويجعل التشغيل يبدأ فورًا.

## ما لا تحتاجه

- VPN إذا كنت تستخدم Debrid أو Usenet فقط.
- عشرين إضافة. كل واحدة تضيف تأخيرًا ونقطة فشل إضافية.
- «سيرفر وسائط» منفصل. ستريمو ليس Plex ولا يفحص مكتبة.
